# PRD：轻享点餐小程序

## 1. 产品概述

「轻享点餐」是一款面向家庭 / 小型团体（公司团建、朋友小聚）场景的极简点餐 H5 应用，参考朴朴小程序的「分类 + 商品 + 购物车」骨架，但**砍掉支付与地址等冗余流程**，点完即下，单击「去结算」即把订单以邮件形式直发指定接收人，并附赠适配本次所点菜品的简版菜谱。

- **目标用户**：家庭主厨、公司行政、组织小聚的活动负责人。
- **核心价值**：把"点菜 → 通知 → 烹饪指引"压缩到 **1 分钟内**完成；无需注册、无需支付、零学习成本。

## 2. 核心功能

### 2.1 用户角色

本产品不设账号体系，区分两类使用身份即可：

| 角色 | 触发方式 | 核心权限 |
|------|----------|----------|
| 点餐人（默认） | 打开小程序 | 浏览菜品、加购、查看菜谱、提交订单并触发邮件 |
| 收单邮箱人 | 收件箱接收 | 接收订单邮件（HTML 美化） |

### 2.2 功能模块

1. **首页 / 点餐页**：顶部搜索 + 左侧分类栏 + 右侧商品瀑布流 + 底部购物车浮窗。
2. **购物车浮层**：展示已选商品、可改数量、可一键清空、显示合计数量。
3. **结算提交弹窗**：填写「取餐人 / 取餐时间 / 备注」三项基本信息，**默认带出**收单邮箱（可改），点确认后触发邮件并展示成功页。
4. **菜谱推荐页**：根据本次所点菜品智能匹配 1–2 道家常做法，含食材清单、步骤、火候提示。
5. **设置页（轻量）**：配置收单邮箱、SMTP 主题前缀，仅本地持久化（localStorage）。

### 2.3 页面与功能细节

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 点餐页 | 顶部搜索框 | 支持按菜名 / 标签模糊匹配本地菜单数据 |
| 点餐页 | 左侧分类 | 固定分类：热销 / 蔬菜 / 肉禽 / 海鲜 / 主食 / 汤品 / 饮品 |
| 点餐页 | 商品卡片 | 展示图片、菜名、简介、价格、「+ / -」加购按钮，已加购数量徽标 |
| 点餐页 | 购物车浮窗 | 悬浮在底部，合计件数 + "去结算"按钮，购物车为空时折叠收起 |
| 结算弹窗 | 表单 | 取餐人、取餐时间（默认 +30min）、备注、收单邮箱（默认读取设置） |
| 结算弹窗 | 确认 | 校验通过后调用邮件 API，弹成功页显示「订单号 + 菜谱推荐」入口 |
| 菜谱页 | 推荐卡 | 标题、用时、难度、食材、步骤、贴士；可左右滑动切换 |
| 设置页 | 邮箱配置 | 收单邮箱、主题前缀；保存后立即生效 |

## 3. 核心流程

```
打开小程序
   │
   ▼
浏览 / 搜索菜品 ──加购──▶ 购物车浮窗
   │                          │
   │                          ▼
   │                     「去结算」按钮
   │                          │
   │                          ▼
   │                  结算弹窗（取餐信息）
   │                          │
   │                          ▼
   │                 提交 ──▶ 调用邮件服务
   │                          │
   │                          ▼
   │              成功页：展示订单号 + 菜谱入口
   │                          │
   │                          ▼
   │                   菜谱推荐页（1~2 道）
   ▼
   继续点餐 / 修改邮箱设置
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：暖橘 `#FF6A2C`（朴朴的橙黄调但更克制）+ 米白 `#FAF7F2` 背景，营造"家"的感觉。
- **辅色**：墨绿 `#2F4A3A` 用于主标题 / 价格高亮；雾灰 `#9AA0A6` 用于次要文字。
- **按钮**：圆角 12px 的大块按钮，**没有任何阴影**，靠 1px 边框 + 轻微缩放反馈传递触感。
- **字体**：标题用「思源宋体」/ Noto Serif SC（温度感），正文用「思源黑体」/ Noto Sans SC，数字用 tabular-nums 等宽对齐。
- **布局**：左 28% 分类栏 + 右 72% 商品流的双列卡片，避免朴朴过于密集的单列堆叠。
- **图标**：使用线性 Emoji + 几何 SVG 自绘图标，不使用 Material/FontAwesome 套件。

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 点餐页 | 顶部 | 高度 56px，logo + 搜索框 + 设置入口；暖橘色 1px 底边 |
| 点餐页 | 分类栏 | 左侧固定 90px 宽度，选中态有 3px 暖橘色左 border + 加粗 |
| 点餐页 | 商品卡 | 圆角 16px，白底，菜名宋体、简介灰色、价格橘色；右下角浮动"+"按钮 |
| 购物车浮窗 | 底部胶囊 | 高度 64px，左侧总价 + 件数，右侧「去结算」橘色按钮 |
| 结算弹窗 | 弹层 | 自下而上滑入，背景米白，标题宋体；表单 label 极简无星号 |
| 成功页 | 居中 | 巨大对勾（自绘 SVG）+ 订单号 + 「查看菜谱」主按钮 |
| 菜谱页 | 卡片 | 一道菜一屏；顶部菜品图，下方步骤编号气泡；可左右滑动 |
| 设置页 | 表单 | 单列 label + input，宽度 100%；底部"保存"橘色按钮 |

### 4.3 响应式

- **主适配**：移动端（375–430px），模拟小程序容器，最大宽度 480px 居中。
- **桌面端**：当视口 > 768px 时，将整个应用居中显示在 420px 宽的"手机框"内，并附带毛玻璃背景。
- **触控**：所有可点击区域 ≥ 44×44 px，按钮按下使用 `scale(0.97)` 反馈。

### 4.4 3D 场景指引

本项目不含 3D 场景，无需 HDRI / 灯光 / 摄像机设置。
